# Changelog

Усі помітні зміни в цьому проєкті документуються в цьому файлі.

## [2026-11-02] — Покращення UX, швидкодії, гарячих клавіш та оптимізація API

### Додано
- **Інтерактивний запис гарячих клавіш (`create_hotkey_recorder`)**: у налаштуваннях API тепер можна змінити шорткати просто клікнувши по кнопці та натиснувши потрібну комбінацію клавіш (із живим прев'ю модифікаторів, автоматичним призупиненням глобальних хоткеїв на час запису та скасуванням через `Esc`).
- **Гаряча клавіша для виправлення помилок (`Ctrl+E` за замовчуванням)**: окремий шорткат для швидкого виправлення граматики й пунктуації виділеного тексту.
- **Кнопка «✍️ Замінити текст» у вікні результату (`replace_from_popup`)**: дозволяє вставити перекладений або виправлений текст із спливаючого вікна (`Ctrl+W` / `Ctrl+E`) одразу у вихідне вікно одним кліком.
- **Кешування результатів у пам'яті (LRU Cache на 64 запити)**: повторний переклад або виправлення того самого фрагмента тексту повертається миттєво без повторного запиту до моделі чи API.
- **Передача контексту розмови до локальної моделі Ollama (`TranslateGemma 4B`)**: поле «Контекст розмови» тепер враховується і під час локального перекладу.
- **Тарифи для актуальних моделей Gemini**: додано розцінки для `gemini-flash-lite-latest`, `gemini-flash-latest` та `gemini-pro-latest` для точного підрахунку вартості сесії у вікні дебагу.

### Змінено та оптимізовано
- **Оптимізація запитів до DeepL (усунення подвійних викликів)**: мова виділеного тексту тепер визначається локально через `lingua` перед зверненням до DeepL, тому при перекладі з основної мови виконується 1 HTTP-запит замість 2 (вдвічі менша затримка та економія місячного ліміту символів).
- **Збереження буфера обміну користувача**: попередній вміст буфера обміну зберігається перед копіюванням виділеного тексту або вставкою перекладу (`Ctrl+Q` / `Ctrl+W`) та автоматично відновлюється після завершення дії.
- **Надійне повернення фокусу при заміні тексту (`target_hwnd`)**: `execute_replace_action` запам'ятовує активне вікно в момент натискання гарячої клавіші та повертає йому фокус безпосередньо перед вставкою `Ctrl+V`.
- **Відкладене збереження налаштувань (Debounce 400 мс) та ліміт логів**: введення тексту в поле контексту більше не викликає синхронне шифрування DPAPI і запис на диск на кожне натискання клавіші; історія дебагу обмежена `deque(maxlen=500)`.
- **Модульність та очищення залежностей**: словники локалізації (`uk`, `ru`, `en`) і тарифів винесено в окремий модуль `translator_i18n.py`; прибрано невикористані залежності (`pynput`, `win32process`); `build.ps1` тепер автоматично зупиняє запущений `Translator.exe` перед перезбіркою.

### Виправлено
- Виправлено `KeyError` у `apply_interface_language`, через який при перемиканні основної мови частина написів головного вікна не змінювала мову до перезапуску.
- Виправлено хибне спрацьовування модифікатора `Alt` у Windows Tkinter під час запису гарячих клавіш при увімкненому `NumLock` (біт `0x0008` у Windows Tk відповідає за `NumLock`, тоді як `Alt` — `0x20000`).
