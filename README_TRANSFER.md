# Перенесення застосунку «Перекладач»

## Варіант для іншого ПК

1. Скопіюйте `dist\Translator.exe` на інший ПК.
2. Python та бібліотеки встановлювати не потрібно.
3. Запустіть `Translator.exe`.
4. Для роботи Gemini задайте змінну середовища `GEMINI_API_KEY`.
5. Для резервного Claude задайте `ANTHROPIC_API_KEY`.

Для перекладу та виправлення тексту використовуйте Gemini або Claude. DeepL доступний як перший провайдер перекладу через офіційний API. Якщо DeepL недоступний, програма переходить до Gemini, а потім Claude. Для «Виправити текст» DeepL не використовується.

Для DeepL відкрийте «Налаштування API», увімкніть DeepL, вставте API-ключ і натисніть «Зберегти». Для безкоштовних ключів використовується `https://api-free.deepl.com/v2/translate`; для Pro-ключа в коді потрібно змінити endpoint на `https://api.deepl.com/v2/translate`.

У вікні «Налаштування API» моделі Gemini та Claude вибираються зі списку. Для Gemini залишені лише стабільні alias-и, придатні для текстового перекладу: `gemini-flash-lite-latest`, `gemini-flash-latest` і `gemini-pro-latest`. Для Claude залишені лише `claude-haiku-4-5-20251001` і `claude-sonnet-4-5-20250929`; Opus та інші експериментальні моделі не використовуються для перекладу. Список моделей тихо оновлюється у фоні при відкритті налаштувань, а під списком показуються опис і орієнтовна ціна. API провайдерів не повертають тарифи разом зі списком моделей, тому для нових моделей ціна може бути позначена як невідома. За замовчуванням використовуються `gemini-flash-lite-latest` і `claude-haiku-4-5-20251001`.

У вікні дебагу після кожного запиту показуються input/output токени, приблизна ціна запиту та накопичений підсумок за поточний запуск. Якщо для вибраної моделі немає підтвердженого тарифу, програма пише «ціна поки невідома» і не підставляє `$0.00`.

Мови перекладу можна впорядкувати через кнопку налаштувань біля напису «Мова перекладу». Доступно 8 вибраних позицій із хоткеями `Ctrl+Alt+1` ... `Ctrl+Alt+8`, а 9-й dropdown призначений для одноразового вибору іншої мови. Мова з 9-го dropdown одразу стає мовою перекладу, але не додається до 8 hotkey-позицій; вибрані 8 мов у ньому не показуються. Якщо окрема комбінація зайнята Windows або іншою програмою, решта хоткеїв продовжує працювати.

У «Налаштування API» можна увімкнути запуск разом із Windows. При натисканні хрестика застосунок запитає, чи згорнути його в системний трей, закрити повністю або скасувати дію. Із трея доступні відкриття вікна та завершення програми.

Автозапуск відбувається після входу користувача у Windows. Застосунок працює зі звичайними правами користувача, без запиту UAC. Не вмикайте «Запускати від імені адміністратора» у властивостях EXE або ярлика: це заважає звичайному автозапуску. Для заміни тексту у програмах, запущених від адміністратора, може знадобитися вручну запустити перекладач із такими самими правами.

У PowerShell для поточного сеансу:

```powershell
$env:GEMINI_API_KEY = "ваш Gemini API ключ"
$env:ANTHROPIC_API_KEY = "ваш Anthropic API ключ"
.\Translator.exe
```

Для запуску через ярлик збережіть змінні середовища як системні або користувацькі змінні Windows, потім перезапустіть Explorer/застосунок.

## Запуск проєкту з GitHub

Встановіть Python 3.14 для Windows. Завантажте проєкт і відкрийте PowerShell у його папці:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\Translator.cmd
```

Надалі запускайте `Translator.cmd` подвійним кліком. Він використовує Python із `.venv`, а якщо цього середовища немає — Python через `py` або `PATH`. Папку проєкту можна перемістити; після переміщення створіть `.venv` заново й перевстановіть залежності, оскільки саме Python-середовище не є переносним. API-ключі введіть у налаштуваннях застосунку на новому ПК.

`Translator.cmd` замінює старий `Translator.lnk`, який містив абсолютні шляхи до ПК розробника. Якщо потрібен ярлик на робочому столі, створіть його для `Translator.cmd` на конкретному ПК. Після переміщення застосунку вимкніть та знову увімкніть автозапуск у його налаштуваннях, щоб оновити шлях Windows.

## Збірка заново

Після встановлення залежностей виконайте:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Готовий файл з'явиться у `dist\Translator.exe`.

Скрипт сам знаходить Python та іконку бібліотеки CustomTkinter. Для вибору конкретного Python передайте `-Python "шлях\до\python.exe"`. Перед повторною збіркою повністю закрийте запущений `Translator.exe` через системний трей.

## Безпека ключів

Не додавайте API-ключі до EXE, git або публічної папки. Застосунок зберігає ключі в `%APPDATA%\translator_settings.json`, зашифрованими Windows DPAPI для поточного користувача. Старі ключі у відкритому форматі автоматично прочитаються й будуть зашифровані під час наступного збереження налаштувань. Ключі, які раніше були записані безпосередньо у `translator.py`, слід відкликати в Google AI Studio та Anthropic Console і створити нові.
