# Перекладач для Windows

Програма перекладає виділений текст у браузері, месенджері або іншій програмі. Можна показати переклад в окремому вікні або замінити ним початковий текст. Знання програмування не потрібні.

Для роботи потрібні **Windows 10 або 11, інтернет і API-ключ хоча б одного сервісу перекладу**. API-ключ — це особистий код доступу, який ви отримуєте на сайті сервісу та вставляєте в налаштування програми. Без ключа вікно програми відкриється, але переклад не працюватиме.

## 1. Виберіть спосіб встановлення

| Що у вас є | Що робити |
| --- | --- |
| Вам передали готовий файл `Translator.exe` | Виконайте розділ 2, потім перейдіть до розділу 4. Python і команди не потрібні. |
| Ви відкрили цей репозиторій на GitHub | Виконайте розділ 3, потім розділ 4. У ZIP-архіві репозиторію готового EXE немає. |

## 2. Якщо вам передали готовий Translator.exe

1. Створіть постійну папку для програми, наприклад `Translator` у «Документах».
2. Скопіюйте туди `Translator.exe`. Якщо отримали ZIP-архів, спочатку натисніть на ньому правою кнопкою → **«Видобути все…» / «Extract All…»**. Не запускайте програму всередині архіву.
3. Двічі клацніть `Translator.exe` і дочекайтеся вікна «Перекладач». Перший запуск може зайняти кілька секунд.
4. Перейдіть до розділу 4 та додайте ключ сервісу.

Не потрібно встановлювати Python, відкривати командний рядок або завантажувати файли коду. Після налаштування запускайте той самий `Translator.exe`.

Для ярлика на робочому столі натисніть на файлі правою кнопкою → за потреби **«Показати додаткові параметри» → «Надіслати» → «Робочий стіл (створити ярлик)»**. Це створює посилання на програму; сам EXE залиште в його папці.

## 3. Якщо ви завантажуєте програму з GitHub

Ці дії потрібні лише один раз. Ви встановите Python — програму, яка запускає код перекладача, — а потім запустите готовий скрипт підготовки. Писати код не потрібно.

### Крок 1. Завантажте й розпакуйте проєкт

1. Відкрийте [сторінку репозиторію](https://github.com/rdolgopolsky/translater).
2. Над списком файлів натисніть зелену кнопку **Code → Download ZIP**.
3. Відкрийте папку «Завантаження», натисніть на завантаженому ZIP правою кнопкою → **«Видобути все…» / «Extract All…»**.
4. Збережіть розпаковану папку в постійному місці, наприклад у «Документах».
5. Відкрийте її. Потрібна саме та папка, де разом лежать `README.md`, `translator.py`, `setup.ps1` і `Translator.cmd`. Якщо бачите лише ще одну папку, відкрийте її.

Не завантажуйте окремо лише `translator.py`: для запуску потрібні й інші файли проєкту.

### Крок 2. Встановіть Python 3.14, 64-bit

Проєкт налаштований на **Python 3.14**. Версію 3.15 або іншу гілку замість нього для цих інструкцій не обирайте.

1. Відкрийте [офіційну сторінку Python 3.14.7](https://www.python.org/downloads/release/python-3147/). Саме з цією версією перевірено збірку.
2. Прокрутіть до списку **Files** і завантажте **Windows installer (64-bit)**.
3. Відкрийте завантажений файл встановлення.
4. Якщо внизу є галочка **Add python.exe to PATH**, увімкніть її.
5. Натисніть **Install Now** та дочекайтеся повідомлення про завершення. Закрийте встановлювач.
6. Якщо PowerShell або термінал уже був відкритий, закрийте його — нижче відкриєте новий.

### Крок 3. Відкрийте PowerShell у папці проєкту

PowerShell — це вікно, куди потрібно вставити одну готову команду.

1. У Провіднику відкрийте папку з файлами `setup.ps1` і `Translator.cmd`.
2. Клацніть адресний рядок угорі Провідника, де показано шлях до папки. Не поле пошуку праворуч.
3. Замість шляху введіть `powershell` і натисніть **Enter**.
4. Відкриється вікно PowerShell. В кінці його поточного шляху має бути ваша папка проєкту.

Права адміністратора для цього не потрібні.

### Крок 4. Підготуйте програму

Скопіюйте **весь рядок нижче**, вставте його в PowerShell правою кнопкою миші або через `Ctrl+V` і натисніть **Enter**:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

Дочекайтеся завершення. Під час роботи завантажуються потрібні компоненти, тому інтернет має бути увімкнений. Рядків англійською буде багато — це нормально. Не закривайте вікно, поки встановлення триває.

**Ознака успіху:** з'явився рядок `Ready. Launch: ...`, а нижче знову можна вводити команду. Якщо бачите червону помилку, перейдіть до розділу 8.

Скрипт створює в папці проєкту службову папку `.venv`. Не видаляйте її, поки користуєтеся програмою.

### Крок 5. Запустіть перекладач

1. Поверніться до папки проєкту в Провіднику.
2. Двічі клацніть **`Translator.cmd`**. Може на мить з'явитися вікно консолі, потім відкриється «Перекладач».
3. Перейдіть до розділу 4 та додайте API-ключ.

Надалі достатньо подвійного кліку на `Translator.cmd`; повторювати встановлення перед кожним запуском не потрібно. Можна створити ярлик для `Translator.cmd` способом із розділу 2.

Якщо розширення файлів приховані, `Translator.cmd` може відображатися просто як `Translator`. Увімкніть показ розширень у меню «Вигляд» Провідника, щоб не переплутати файли. Для запуску не потрібно відкривати `translator.py`, `Translator.spec` або `launch.ps1`.

## 4. Отримайте API-ключ і додайте його

Достатньо **одного** сервісу. Не потрібно реєструватися в усіх трьох.

| Сервіс | Що дає в цьому застосунку | Де отримати ключ |
| --- | --- | --- |
| DeepL API Free | Переклад тексту | [DeepL для розробників](https://www.deepl.com/en/developers), [офіційна інструкція щодо ключів](https://support.deepl.com/hc/en-us/articles/360020695820-API-key-for-DeepL-API) |
| Gemini | Переклад і виправлення тексту | [Google AI Studio](https://aistudio.google.com/), [офіційна інструкція](https://ai.google.dev/gemini-api/docs/api-key) |
| Claude | Переклад і виправлення тексту; також може бути резервним сервісом | [Ключі Claude Console](https://platform.claude.com/settings/keys), [офіційна інструкція](https://platform.claude.com/docs/en/get-api-key) |

API — це окремий доступ для програм. Звичайний обліковий запис або платна підписка на чат чи сайт перекладача самі по собі не замінюють API-ключ. Умови, ліміти й оплата залежать від сервісу; перевірте їх у власному кабінеті перед використанням. Застосунок не скасовує ці обмеження.

**Важливо для DeepL:** поточна версія застосунку налаштована на адресу сервісу **API Free**. Для цієї інструкції використовуйте ключ DeepL API Free. Ключ DeepL API Pro потребує зміни адреси сервісу в коді та повторної збірки — простого вставлення Pro-ключа недостатньо.

### Як отримати ключ

1. Виберіть сервіс у таблиці та відкрийте його офіційний сайт.
2. Увійдіть або створіть обліковий запис.
3. Відкрийте розділ API-ключів. Для DeepL потрібен саме доступ **DeepL API**; для Gemini — **Google AI Studio**; для Claude — **Claude Console**.
4. Створіть ключ, якщо його ще немає, та скопіюйте його кнопкою копіювання на сайті. Якщо сервіс просить налаштувати оплату або активувати API-доступ, це робиться в його кабінеті.
5. Скопіюйте лише сам ключ, без лапок, пояснень і зайвих пробілів. Нікому його не надсилайте.

Назви кнопок на сайтах можуть змінюватися; офіційні інструкції в таблиці пояснюють актуальний порядок.

### Як вставити ключ у перекладач

1. У вікні «Перекладач» натисніть **шестерню у верхньому правому куті**.
2. У «Налаштування API» увімкніть галочку потрібного сервісу: **«Використовувати DeepL»**, **«Використовувати Gemini»** або **«Використовувати Claude»**.
3. Під галочкою з'явиться поле ключа. За потреби прокрутіть налаштування вниз.
4. Натисніть **«Вставити»** біля потрібного поля. Також можна клацнути в поле й натиснути `Ctrl+V`, `Shift+Insert` або праву кнопку миші → «Вставити».
5. Замість букв ключа з'являться приховані символи — так і має бути.
6. Якщо вибрали Gemini або Claude, для першого запуску залиште запропоновану модель.
7. Вимкніть галочки сервісів, якими не плануєте користуватися.
8. Натисніть **«Зберегти»** внизу вікна. Саме ця кнопка зберігає API-ключі; закриття вікна хрестиком цього не робить.

Після збереження не потрібно вставляти ключ перед кожним запуском. Змінні середовища або команди з ключами для звичайного налаштування не потрібні.

Якщо налаштовано кілька сервісів, програма спочатку пробує DeepL для перекладу, потім Gemini, потім Claude, коли попередній сервіс недоступний. Для дії «Виправити текст» потрібен Gemini або Claude — DeepL для неї не використовується.

## 5. Зробіть перший переклад

1. Залиште «Перекладач» запущеним.
2. У головному вікні виберіть **основну мову**, наприклад українську, і **мову перекладу**, наприклад англійську.
3. Відкрийте звичайний Блокнот Windows. Напишіть: `Привіт! Як справи?`
4. Виділіть цей текст мишею або натисніть `Ctrl+A` в Блокноті.
5. **Залишаючись у Блокноті**, натисніть `Ctrl+W`: утримуйте `Ctrl`, коротко натисніть `W` і відпустіть обидві клавіші. З'явиться окреме вікно з перекладом. Поки чекаєте, не перемикайтеся в іншу програму.
6. Щоб перевірити заміну тексту, закрийте вікно результату, знову виділіть фразу в Блокноті та натисніть `Ctrl+Q`. Програма замінить виділене перекладом.

Для заміни потрібно, щоб текст можна було редагувати. Наприклад, у полі повідомлення його замінити можна, а звичайний текст чужого повідомлення чи сторінки краще перекладати через `Ctrl+W`.

**Напрямок перекладу:** текст основною мовою перекладається обраною іноземною; текст іншою мовою — основною. Наприклад, за основної української й обраної англійської українська фраза піде англійською, а англійська — українською.

### Основні кнопки та гарячі клавіші

Гаряча клавіша — це комбінація кнопок на клавіатурі, яку натискають одночасно.

| Дія | Як виконати |
| --- | --- |
| Показати переклад виділеного тексту в окремому вікні | `Ctrl+W` |
| Замінити виділений текст перекладом | `Ctrl+Q` |
| Обрати одну з восьми збережених мов | `Ctrl+Alt+1` … `Ctrl+Alt+8` |
| Вставити текст у поле програми | `Ctrl+V`, `Shift+Insert` або меню правої кнопки |
| Вставити API-ключ | Кнопка «Вставити» біля поля ключа |

Комбінації працюють також з українською розкладкою. Коли перекладач працює, він займає свої глобальні комбінації: наприклад, `Ctrl+W` може викликати переклад замість закриття вкладки браузера.

Вісім мов можна впорядкувати шестернею біля «Мова перекладу». Пункт «Інша мова…» дозволяє разово обрати ще одну мову, не змінюючи ці вісім позицій. Поле «Контекст розмови» необов'язкове: для першої перевірки залиште його порожнім.

## 6. Автозапуск, згортання та закриття

Щоб програма запускалася після входу у Windows:

1. Відкрийте верхню шестерню → «Налаштування API».
2. Увімкніть **«Запускати разом із Windows»**.
3. Ця галочка зберігається одразу, окремо від API-ключів. Для її вимкнення просто зніміть галочку.

Залиште файл і папку програми на їхньому місці. Якщо перенесли їх, відкрийте програму з нового місця, вимкніть і знову увімкніть автозапуск, щоб Windows запам'ятала нову адресу.

При натисканні хрестика головного вікна можна:

- **Згорнути в трей** — вікно сховається, перекладач продовжить працювати. Трей — це значки біля годинника Windows; частина може бути під стрілкою `^`.
- **Закрити застосунок** — повністю завершити роботу. Гарячі клавіші перекладача перестануть діяти.
- **Скасувати** — повернутися до вікна.

Якщо вибір було запам'ятовано, запит може більше не з'являтися. Щоб відкрити або повністю закрити програму з трея, натисніть її значок правою кнопкою та оберіть потрібну дію. Не запускайте кілька копій одночасно: вони можуть заважати одна одній реєструвати гарячі клавіші.

## 7. Як отримати власний EXE з проєкту

Це необов'язково. Якщо `Translator.cmd` уже працює, для щоденного використання збірка не потрібна. Власний EXE зручний, якщо хочете запускати програму без Python або передати її іншій людині.

1. Спочатку повністю виконайте розділ 3.
2. Повністю закрийте перекладач, зокрема через значок у треї. Просто сховати вікно недостатньо.
3. Відкрийте PowerShell у папці проєкту способом із розділу 3.
4. Вставте команду та натисніть Enter:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
   ```

5. Дочекайтеся рядка **`Built:`** зі шляхом до файлу. Збірка може тривати кілька хвилин.
6. У папці проєкту відкрийте папку **`dist`**. У ній буде готовий **`Translator.exe`**.
7. Можна скопіювати цей EXE в постійну окрему папку або передати на інший ПК з Windows. На іншому ПК людина вводить власний API-ключ через налаштування.

Якщо переходите із запуску через `Translator.cmd` на EXE й користуєтеся автозапуском, відкрийте EXE, вимкніть та знову увімкніть відповідну галочку.

## 8. Якщо щось не працює

| Проблема | Що перевірити або зробити |
| --- | --- |
| У ZIP немає `Translator.exe` | Це нормально: готовий EXE не зберігається в репозиторії. Скористайтеся розділом 3 або зберіть його за розділом 7. |
| PowerShell пише, що `setup.ps1` не знайдено | Відкрийте PowerShell саме в папці, де видно `setup.ps1`, а не в «Завантаженнях», ZIP-архіві чи зовнішній папці. |
| Помилка `Python 3.14 is unavailable` або згадка про іншу версію Python | Встановіть Python 3.14 (64-bit) за розділом 3. Закрийте PowerShell, відкрийте заново та повторіть підготовку. |
| Підготовка перервалася під час завантаження компонентів | Перевірте інтернет і повторіть ту саму команду `setup.ps1`. Скрипт можна запускати повторно. Якщо помилка повторюється, збережіть її повний текст. |
| Після подвійного кліку на `Translator.cmd` видно помилку | Спочатку виконайте підготовку з розділу 3. Вікно з помилкою можна сфотографувати для людини, яка допомагає налаштувати програму. |
| Програма відкривається, але перекладу немає | Перевірте інтернет, галочку потрібного сервісу, його ключ і натискання «Зберегти». Спробуйте коротку фразу в Блокноті. |
| Ключ не вставляється | Заново скопіюйте сам текст ключа на сайті сервісу та натисніть «Вставити» біля поля. Якщо в буфері картинка або файл, текстовий ключ звідти не з'явиться. |
| Помилка ключа, доступу, балансу або ліміту | Перевірте ключ, API-доступ і ліміти в кабінеті відповідного сервісу. Для DeepL перевірте, що використовуєте ключ API Free. |
| «Виправити текст» не працює, хоча DeepL перекладає | Для виправлення додайте та увімкніть Gemini або Claude. |
| Гаряча клавіша не реагує | Переконайтеся, що програма працює, текст виділено, а фокус залишився в його вікні. Закрийте зайві копії перекладача. Інша програма може займати таку саму комбінацію. |
| У дебагу «Ctrl+C не змінив буфер обміну» або «Текст не знайдено» | Спробуйте виділити й скопіювати текст звичайним `Ctrl+C` у тій програмі. Якщо копіювання заборонене або текст не виділяється, перекладач теж не зможе його отримати. Спочатку перевірте роботу в Блокноті. |
| Не працює заміна тексту лише в окремій програмі | Поле має дозволяти редагування. Якщо цільову програму запущено від адміністратора, її права можуть заважати звичайному перекладачу. Для першої перевірки використовуйте звичайний Блокнот. |
| Закрив вікно, але гарячі клавіші ще діють | Програма згорнулася в трей. Закрийте її через значок біля годинника. |
| Автозапуск перестав працювати після перенесення файлів | Запустіть програму з нового місця й вимкніть та знову увімкніть галочку автозапуску. Не позначайте EXE як такий, що завжди запускається від адміністратора. |
| Збірка не може замінити `Translator.exe` | Повністю закрийте запущений EXE через трей і повторіть команду збірки. |
| Після перенесення папки на інший ПК запуск через CMD не працює | Встановіть Python 3.14 на новому ПК та повторіть `setup.ps1`. Не копіюйте лише службову папку `.venv`: вона не є переносним встановленням. |

У головному вікні є кнопка **«Відкрити дебаг»**. Це журнал подій і помилок: він допомагає зрозуміти, який сервіс відповів і що пішло не так. Там також може бути текст, який ви перекладали, тому перегляньте журнал перед тим, як надсилати його комусь.

## 9. Де зберігаються налаштування та що передається сервісам

Ключі й налаштування зберігаються для вашого користувача Windows у файлі:

```text
%APPDATA%\translator_settings.json
```

Щоб знайти папку, вставте `%APPDATA%` в адресний рядок Провідника й натисніть Enter. Для звичайної роботи цей файл не потрібно відкривати або редагувати. Програма використовує захист ключів Windows DPAPI; не вважайте файл налаштувань придатним для публікації або передачі іншим людям.

Не надсилайте іншим свої ключі, файл налаштувань або скриншоти з видимими ключами. При передачі EXE ключ отримувача налаштовується окремо. Якщо ключ випадково опублікували, відкличте його на сайті сервісу та створіть новий.

Переклад виконується через інтернет: виділений текст надсилається сервісу, який обробляє запит. Для Gemini та Claude до запиту також додається заповнений вами контекст розмови. Зважайте на це, коли перекладаєте особисту чи робочу інформацію.
