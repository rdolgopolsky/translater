# Локальний переклад через Ollama: встановлення з нуля

Це інструкція для Windows без досвіду програмування. Потрібно встановити дві окремі програми — **Ollama** і **«Перекладач»** — та один раз завантажити модель **TranslateGemma 4B**. Після цього можна перекладати виділений текст гарячими клавішами. Якщо локальний переклад не спрацює, резервом буде DeepL.

**Ця можливість є в актуальній версії перекладача в гілці `main`.** Старий EXE без галочки «Перекладати локально через Ollama» її не підтримує. Саме встановлення Ollama не додасть цю функцію до старого перекладача.

## Що саме встановлюємо

| Компонент | Для чого він потрібний |
| --- | --- |
| Ollama | Запускає модель на вашому комп'ютері. Має працювати у фоні. |
| `translategemma:4b` | Модель, яка перекладає текст. Завантажується окремо через Ollama. |
| «Перекладач» | Виділення тексту, `Ctrl+W`, `Ctrl+Q`, налаштування мов і перехід до резерву. |
| Ключ DeepL API Free | Доступ до резервного перекладу через інтернет. Для самого локального перекладу ключ не потрібний. |
| Python 3.14 | Потрібний лише при запуску перекладача з файлів GitHub. Якщо отримали готовий EXE, Python не потрібний. |

Не потрібно встановлювати всі моделі, створювати облікові записи в усіх AI-сервісах або писати код.

## Перед початком

- Потрібна Windows 10 **22H2 або новіша** чи Windows 11. Вимоги Ollama — в [офіційній інструкції для Windows](https://docs.ollama.com/windows).
- Інтернет потрібний для завантаження програм і моделі, а також для резервного DeepL. Після встановлення сама локальна модель може перекладати без інтернету.
- Плануйте приблизно **10 ГБ вільного місця** для встановлення й завантажень із запасом. Якщо збираєте EXE самостійно, знадобиться додаткове місце для робочих файлів.
- Для цього варіанта варто орієнтуватися на **16 ГБ оперативної пам'яті або більше**. Це практичний орієнтир, а не гарантія швидкості чи офіційний мінімум моделі. Модель і її робочі дані займають кілька гігабайтів пам'яті.
- Сумісна відеокарта допомагає отримати швидкий переклад. На процесорі може бути суттєво повільніше. Перевірте свою карту й драйвери в [офіційному списку обладнання Ollama](https://docs.ollama.com/gpu). Не кожна відеокарта підтримується однаково.

На комп'ютері іншої людини швидкість може відрізнятися від тієї, яку ви бачили в автора програми.

## Крок 1. Встановіть Ollama

1. Відкрийте [офіційну сторінку завантаження Ollama для Windows](https://ollama.com/download/windows).
2. Оберіть завантаження встановлювача для **Windows**. Якщо сайт пропонує команду встановлення, шукайте варіант **Download manually** для Windows. Потрібний файл називається `OllamaSetup.exe`, не файл для macOS з розширенням `.dmg`.
3. Відкрийте завантажений встановлювач і виконайте його вказівки.
4. Після встановлення відкрийте меню «Пуск», знайдіть **Ollama** й запустіть її.
5. Вікно Ollama можна сховати, але поки не обирайте **Quit / Exit / Вийти** у її меню: це може зупинити фонову роботу.

Перекладач звертається до Ollama на цьому ж комп'ютері. Для цього не потрібно відкривати доступ до комп'ютера з інтернету або змінювати мережеві адреси.

## Крок 2. Виберіть папку для моделі — необов'язково

**Якщо на системному диску вистачає місця, пропустіть цей крок.** Стандартна папка моделей — `.ollama\models` у папці вашого користувача Windows. Не обов'язково повторювати шлях автора `D:\Ollama`.

Якщо хочете зберігати модель, наприклад, у **`D:\Ollama\models`**, налаштуйте це **до завантаження**:

1. Переконайтеся, що у вас справді є диск `D:`. Якщо такого диска немає, використайте наявний диск або стандартне розміщення.
2. У Провіднику створіть на ньому папку `Ollama`, а всередині — `models`.
3. У меню «Пуск» почніть вводити **«змінні середовища»**. Відкрийте **«Редагування змінних середовища для облікового запису» / «Edit environment variables for your account»**. Якщо відкрили властивості системи, натисніть кнопку «Змінні середовища…».
4. У верхній частині вікна, **«Змінні користувача»**, натисніть «Створити…». Якщо `OLLAMA_MODELS` уже є, оберіть її та натисніть «Змінити…».
5. Введіть ім'я: `OLLAMA_MODELS`.
6. Введіть значення: `D:\Ollama\models` — без лапок.
7. Підтвердьте зміни кнопками **OK** у відкритих вікнах.
8. Повністю завершіть Ollama через її значок біля годинника → **Quit / Exit**. Значок може бути під стрілкою `^`.
9. Заново відкрийте Ollama через «Пуск». Уже відкритий PowerShell закрийте й відкрийте новий.

Ця змінна задає папку **моделей**; сама програма Ollama може залишатися встановленою на диску `C:`. Зміна шляху не переносить автоматично вже завантажені моделі. Якщо Ollama налаштована й моделі вже працюють, без потреби не змінюйте цей параметр. [Офіційна інструкція щодо розміщення моделей](https://docs.ollama.com/windows#changing-model-location)

## Крок 3. Відкрийте PowerShell і перевірте Ollama

PowerShell — це вікно для готових команд. Їх потрібно копіювати цілком, по одному рядку, і натискати **Enter** після кожного рядка. Символи оформлення навколо команд копіювати не потрібно.

1. Відкрийте «Пуск», введіть **PowerShell** та запустіть **Windows PowerShell** звичайним способом. Адміністратор для наведених команд не потрібний.
2. Скопіюйте цей рядок, вставте через `Ctrl+V` або праву кнопку миші й натисніть Enter:

   ```powershell
   ollama --version
   ```

3. Має з'явитися номер версії. Якщо написано, що `ollama` не знайдено, закрийте PowerShell і відкрийте його заново після встановлення. Якщо це не допомогло, дивіться таблицю помилок унизу.

Для команд Ollama неважливо, яку папку зараз показує PowerShell. Для команд підготовки самого перекладача папка вже буде важлива — це пояснено в кроці 5.

## Крок 4. Завантажте саме TranslateGemma 4B

У тому ж PowerShell виконайте:

```powershell
ollama pull translategemma:4b
```

- Це завантажує модель, а не відкриває чат. Потрібно близько **3,3 ГБ** завантаження; файл і його формат описані на [сторінці моделі](https://ollama.com/library/translategemma:4b).
- Дочекайтеся завершення та повідомлення **`success`**. Не закривайте PowerShell під час завантаження.
- Назва має бути **`translategemma:4b`**. Не замінюйте її на `gemma`, `gemma4`, версію `12b`, `27b` або назву з `:cloud`: перекладач налаштований саме на вказану модель.
- Завантаження достатньо виконати один раз для цього комп'ютера та папки моделей.

Перевірте результат:

```powershell
ollama list
```

**Ознака успіху:** у списку є рядок `translategemma:4b`. Можуть бути й інші моделі — вони не заважають установленню.

Якщо вже вмієте користуватися чатом Ollama, для нашого застосунку не потрібно щоразу вибирати TranslateGemma в цьому чаті або залишати відкритий діалог із нею. Важливо, щоб модель була завантажена й Ollama працювала у фоні. Команди описані в [довідці Ollama](https://docs.ollama.com/cli).

## Крок 5. Встановіть версію «Перекладача» з підтримкою Ollama

### Варіант А: вам передали готовий Translator.exe

1. Уточніть, що це **нова версія з Ollama**, а не старий EXE.
2. Якщо отримали архів, натисніть на ньому правою кнопкою → «Видобути все…». Не запускайте EXE всередині ZIP.
3. Покладіть `Translator.exe` у постійну папку, наприклад «Документи\Translator».
4. Запустіть його подвійним кліком і перейдіть до кроку 6.

Python і файли коду в цьому варіанті не потрібні. Але **Ollama та модель на цьому ПК усе одно потрібні**: вони не вбудовані в EXE. Простого копіювання EXE з іншого ПК недостатньо для локального перекладу.

### Варіант Б: ви берете файли з GitHub

1. Відкрийте [репозиторій](https://github.com/rdolgopolsky/translater).
2. Над списком файлів переконайтеся, що вибрана гілка **`main`**. Вона містить версію з підтримкою Ollama.
3. Натисніть **Code → Download ZIP** та повністю розпакуйте архів у постійну папку.
4. Встановіть **Python 3.14, 64-bit**. Перевірений встановлювач — **Windows installer (64-bit)** на [офіційній сторінці Python 3.14.7](https://www.python.org/downloads/release/python-3147/). У встановлювачі увімкніть **Add python.exe to PATH**, якщо така галочка є, і натисніть **Install Now**.
5. Відкрийте в Провіднику розпаковану папку, де разом лежать `setup.ps1`, `Translator.cmd`, `translator.py` та **`ollama_translation.py`**. Якщо останнього файлу немає, ви завантажили стару версію або відкрили не ту папку.
6. У цій папці клацніть адресний рядок Провідника, замість шляху введіть `powershell` і натисніть Enter. Це відкриє PowerShell саме в потрібному місці.
7. Виконайте:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
   ```

8. Дочекайтеся рядка **`Ready. Launch: ...`**. Підготовка потребує інтернету; вона встановить і засіб локального визначення мови. Вручну завантажувати Python-бібліотеки не потрібно.
9. Поверніться до Провідника й двічі клацніть **`Translator.cmd`**. Надалі запускайте цей файл, не повторюючи підготовку щоразу.

Детальніші пояснення встановлення Python, розпакування та пошуку потрібної папки — у [головному README](README.md). Службову папку `.venv` не потрібно відкривати чи переносити окремо.

## Крок 6. Увімкніть локальний переклад

1. Залиште Ollama запущеною.
2. У головному вікні «Перекладача» натисніть **шестерню у верхньому правому куті**.
3. Знайдіть галочку **«Перекладати локально через Ollama»** та увімкніть її. У новій версії вона вже ввімкнена за замовчуванням.
4. Натисніть **«Зберегти»** внизу налаштувань. За потреби прокрутіть вміст вікна.
5. Для першої перевірки виберіть основну мову **українську**, мову перекладу — **англійську**.

Поле для ключа Ollama заповнювати не потрібно — його немає. Не вставляйте ключ DeepL у поля Gemini або Claude.

Якщо галочки Ollama немає, перевірте версію перекладача за кроком 5. Якщо отримали оновлений EXE, повністю закрийте старий перекладач через значок біля годинника й запустіть новий файл. Не запускайте кілька копій одночасно.

## Крок 7. Додайте DeepL як автоматичний резерв

Для цього сценарію потрібний саме **DeepL API Free**. Ключ DeepL API Pro поточна версія без зміни коду не підтримує.

1. Відкрийте [офіційну сторінку DeepL для розробників](https://www.deepl.com/en/developers).
2. Увійдіть або створіть обліковий запис і оформіть доступ **DeepL API Free**, якщо він доступний для вашого облікового запису. Умови та ліміти перевірте на сайті сервісу.
3. У кабінеті знайдіть API-ключ. Для пошуку скористайтеся [офіційною інструкцією DeepL](https://support.deepl.com/hc/en-us/articles/360020695820-API-key-for-DeepL-API). Звичайний пароль від DeepL або підписка на вебперекладач не замінюють цей ключ.
4. Скопіюйте сам текст ключа, без лапок. Не надсилайте його автору програми чи іншим людям.
5. У налаштуваннях «Перекладача» залиште галочку Ollama ввімкненою та увімкніть **«Використовувати DeepL»**.
6. Біля **«Ключ DeepL API»** натисніть **«Вставити»**. У полі з'являться приховані символи.
7. Якщо не користуєтеся Gemini та Claude, вимкніть їхні галочки. Для комбінації «Ollama + DeepL» вони не потрібні.
8. Натисніть **«Зберегти»**. Ключ не потрібно повторно вводити після кожного запуску.

**Результат:** спочатку працює локальна TranslateGemma. Якщо вона недоступна чи запит завершується помилкою, застосунок звертається до DeepL. DeepL має працювати через інтернет, а його API-ключ — бути чинним.

Якщо не хочете налаштовувати DeepL, локальний переклад усе одно працюватиме, але цього резерву не буде. Якщо вимкнете всі хмарні сервіси, у разі збою Ollama перекладу не буде.

## Крок 8. Перевірте роботу в Блокноті

1. Відкрийте звичайний Блокнот Windows.
2. Напишіть `Привіт! Як справи?`.
3. Виділіть цей текст мишею або натисніть `Ctrl+A` в Блокноті.
4. Залишаючись у Блокноті, натисніть **`Ctrl+W`**: утримуйте Ctrl, натисніть W і відпустіть обидві клавіші.
5. Дочекайтеся вікна перекладу. Під час першого запуску модель завантажується в пам'ять; наступні переклади можуть бути значно швидшими.
6. **Перевірте назву сервісу над текстом:** напис **`Ollama • TranslateGemma`** означає локальний маршрут. У дебагу успішний локальний запит має рядок `Ollama: translategemma:4b; ... translation complete`.
7. Закрийте результат кнопкою, хрестиком або Escape. Для перевірки зворотного напрямку напишіть і виділіть `Hello! How are you doing today?` — має з'явитися український переклад.
8. Для заміни тексту в Блокноті виділіть фразу та натисніть **`Ctrl+Q`**. Це змінить текст у самому полі, тому спочатку тренуйтеся на тестовій фразі.

Якщо у вікні написано **DeepL**, переклад отримано від резерву. Це не підтверджує справність локальної моделі: перевірте Ollama й список моделей за кроками 3–4. Журнал помилок відкривається кнопкою **«Відкрити дебаг»**.

## Крок 9. Перевірте резерв без аварійного закриття програм

Не потрібно навмисно завершувати процеси через диспетчер завдань.

1. Переконайтеся, що DeepL увімкнений і його ключ збережений.
2. Тимчасово зніміть галочку **«Перекладати локально через Ollama»** й натисніть «Зберегти».
3. Перекладіть тестову фразу в Блокноті через `Ctrl+W`. У вікні результату має бути **DeepL**.
4. Поверніть галочку Ollama та знову натисніть «Зберегти».

Це перевіряє працездатність резервного сервісу. При справжній помилці Ollama застосунок обирає резерв автоматично; знімати галочку вручну тоді не потрібно. Неправильний за змістом переклад сам по собі не завжди розпізнається як помилка.

## Як користуватися щодня

1. Запустіть Ollama через «Пуск», якщо вона ще не працює у фоні.
2. Запустіть «Перекладач»: `Translator.exe` або `Translator.cmd`, залежно від вашого способу встановлення.
3. Дайте моделі завантажитися в пам'ять. Не потрібно запускати `ollama pull` повторно чи відкривати чат із моделлю.
4. Виділяйте текст у потрібному вікні та використовуйте `Ctrl+W` або `Ctrl+Q`.

Автозапуск перекладача вмикається його галочкою «Запускати разом із Windows». Вона керує лише перекладачем, а не встановленням чи автозапуском Ollama. Після перезавантаження переконайтеся, що працюють обидві програми. Якщо Ollama ще не встигла запуститися, перші запити можуть піти до DeepL.

Вибір іншої моделі в чаті Ollama **не перемикає модель перекладача**: він використовує `translategemma:4b` окремо. За достатньої пам'яті можна працювати з іншими моделями паралельно. Якщо модель доведеться завантажувати знову, буде затримка; у разі тайм-ауту спрацює резерв.

## Що відбувається при помилках і з пам'яттю

- Після помилки локального перекладу застосунок пробує DeepL. Якщо й він недоступний, може звернутися до Gemini, потім Claude — лише якщо вони ввімкнені та мають ключі.
- Тайм-аут мережевого запиту до Ollama — **25 секунд**. Після збою локальний сервіс пропускається **60 секунд**, щоб не затримувати кожний наступний запит; потім застосунок знову пробує локальний переклад.
- Тексти понад **6000 символів** спрямовуються до резервного маршруту. Короткі неоднозначні фрази можуть визначатися не тією мовою; це не завжди запускає резерв.
- Застосунок попередньо завантажує модель і періодично підтримує її в пам'яті. При нормальному завершенні надсилає запит на вивантаження. Після аварійного завершення пам'ять може залишатися зайнятою до 10 хвилин після останнього звернення.
- Згортання перекладача в трей не завершує його роботу: модель залишається потрібною. Щоб завершити роботу, використовуйте «Закрити застосунок» або «Закрити» в меню значка біля годинника.
- «Виправити текст» використовує Gemini або Claude. TranslateGemma й DeepL у цій версії відповідають за переклад.

Для перегляду завантажених у пам'ять моделей у PowerShell можна виконати:

```powershell
ollama ps
```

У рядку `translategemma:4b` подивіться стовпець **PROCESSOR**. `100% GPU` означає використання відеокарти, `100% CPU` — оперативної пам'яті й процесора, змішане значення — часткове розміщення. Якщо рядка ще немає, модель може бути не завантажена; спочатку відкрийте перекладач і виконайте короткий переклад. [Пояснення в документації Ollama](https://docs.ollama.com/faq#how-can-i-tell-if-my-model-was-loaded-onto-the-gpu)

## Якщо щось не працює

| Що бачите | Що зробити |
| --- | --- |
| `ollama` не знайдено / `not recognized` | Закрийте старий PowerShell і відкрийте новий після встановлення. Перевірте, що встановлення Ollama завершилося. Якщо її встановлювали нестандартно, попросіть людину, яка це робила, перевірити шлях до програми. |
| Команда показує, що не може під'єднатися до Ollama | Відкрийте Ollama через «Пуск». Після запуску повторіть `ollama list`. Не запускайте кілька серверів Ollama одночасно. |
| Завантаження моделі перервалося | Перевірте інтернет і вільне місце, потім повторіть `ollama pull translategemma:4b`. |
| У списку є інші моделі, але немає `translategemma:4b` | Завантажте саме `translategemma:4b`. Модель із подібною назвою не підставляється автоматично. |
| Модель завантажена, але перекладач її не бачить | Перевірте `ollama list` у тому ж обліковому записі Windows. Після зміни `OLLAMA_MODELS` перезапустіть Ollama; сама зміна папки не переносить попередні моделі. Програма очікує Ollama на цьому ПК зі стандартним портом 11434. |
| У налаштуваннях немає галочки Ollama | Це стара версія перекладача. Потрібний EXE з підтримкою Ollama або код із відповідної гілки; закрийте стару копію через трей перед запуском нової. |
| Після оновлення коду помилка про `lingua` | Повторіть підготовку через `setup.ps1` у папці проєкту. Для готового EXE потрібен актуальний зібраний файл, а не встановлення Python-бібліотек вручну. |
| Усе перекладається через DeepL | Перевірте галочку Ollama, `ollama list`, запущену Ollama та дебаг. Після усунення збою врахуйте паузу повторної спроби 60 секунд. |
| Перший переклад довгий, наступні швидкі | Модель спочатку завантажується в пам'ять. Це очікувано; довге початкове завантаження може спричинити перехід до резерву. |
| Переклад постійно довгий або виникає тайм-аут | Перевірте `ollama ps`, завантаження пам'яті та сумісність відеокарти. Закрийте зайві важкі програми або оберіть DeepL, вимкнувши Ollama. Оновлення драйверів і вимоги перевіряйте за офіційними посиланнями на початку інструкції. |
| Не працює без інтернету | Перевірте, що модель уже завантажена й обробляє запит локально. DeepL та інші хмарні резерви без інтернету не працюватимуть. |
| DeepL повертає помилку ключа | Перевірте доступ саме до DeepL API Free, правильне поле, ключ і натискання «Зберегти». Не використовуйте пароль від сайту замість ключа. |
| Переклад не тією мовою | Перевірте основну й цільову мови. Спробуйте повне речення замість одного слова: локальне визначення короткого тексту може помилятися. |
| Копіювання або заміна не працюють лише в окремій програмі | Спочатку перевірте Блокнот. У цільовій програмі має працювати звичайне копіювання, а для `Ctrl+Q` поле має дозволяти редагування. |

## Передача іншій людині та приватність

Передайте актуальний EXE або посилання на потрібну версію коду та цю інструкцію. Отримувач встановлює Ollama, завантажує модель і додає **власний** ключ DeepL. Ваші папки `.venv`, налаштування та ключі копіювати не потрібно.

Локальний текст обробляється на вашому ПК. При переході до резерву текст надсилається відповідному хмарному сервісу. Якщо потрібна виключно локальна обробка, вимкніть DeepL, Gemini та Claude — але тоді хмарного резерву не буде. Перед передачею журналу помилок перегляньте його: у ньому можуть бути фрагменти перекладеного тексту.

**Підсумкова перевірка:** Ollama встановлена й запущена; `ollama list` показує `translategemma:4b`; у перекладачі ввімкнено Ollama; тест у Блокноті показує `Ollama • TranslateGemma`; резервний тест показує DeepL; після перевірки галочку Ollama повернуто.
